# DUO Trainer

DUO 3.0 の例文を **「思い出す練習」×「間隔を空けた復習」** で覚えるための、自分用 Android アプリです。
UI は abceed の「白地・大きな数字・カード」の雰囲気を、Material 3（Jetpack Compose）で作っています。

> **教材データは含まれていません。** DUO 3.0 の例文・訳・音声は著作権で保護されています。
> このリポジトリにはアプリのコードだけを置き、データは各自が手元のファイルをアプリに読み込みます（端末の中だけで使われ、どこにも送信しません）。

## できること

| 機能 | 内容 |
| --- | --- |
| 今日の復習 | ホームの大きなボタンから。期限の来た例文＋新しい例文（1 日 10 文など）を出題 |
| 3 段階の仕分け | 答え合わせのあとに **苦手 / 正解 / 簡単** を選ぶ。ボタンの下に「次はいつ出るか」を表示。**仕分けに入るのは和文英訳だけ**（ほかのモードは練習扱いで、苦手 / 正解 のみ） |
| 分散学習 | エビングハウスの忘却曲線を参考に、思い出せるたびに間隔を少しずつ伸ばす（1 日 → 3 日 → 約 1 週間 → 約 3 週間 → 約 2 か月…）。苦手にした文はその回の中で数問あとにもう一度出し、明日に戻す |
| 自信度 | 「わからない / たぶん / 自信あり」を押すと、そのまま答えが出る。復習間隔の調整に使う |
| 和文英訳（入力なし） | 日本語訳を見て頭の中で英訳し、答えを見て自分で判定（入力なし） |
| 和文英訳（入力あり） | 日本語訳を見て英文を書く（マイクで音声入力も可）。単語単位で差分を表示 |
| 苦手をランダムに | 苦手にした例文の日本語訳がランダムに出る |
| 穴埋め | DUO の見出し語（熟語は once and for all の and for まで丸ごと）を空欄にする |
| 語順パズル | 単語をタップで並べ、ドラッグで順番を入れ替える |
| ディクテーション | 音声を聞いて書き取る（ゆっくり再生あり） |
| シャドーイング | 音声のあとを追って声に出す。マイクで言えたか確認 |
| 単語テスト | 意味から見出し語を 4 択で選ぶ。その単語が出てくる例文も表示 |
| インターリービング | 復習は違うセクションの例文を混ぜて出す。「今は難しく感じて大丈夫」のひと言つき |
| 記録 | 連続学習日数、日別の学習時間・正解率のグラフ、セクション別の定着度マップ |
| バックアップ | 学習記録を JSON で書き出し・読み込み（機種変更用） |

## 使い方

### 1. APK を入れる

GitHub の **Releases → 「最新ビルド」(latest)** から `duo-trainer.apk` をスマホでダウンロードしてインストールします。
（main に push するたびに GitHub Actions が自動でビルドして差し替えます。初回は「提供元不明のアプリ」の許可が必要です。）

### 2. 例文データを読み込む

Anki から書き出した DUO 3.0 のテキスト（タブ区切り）をスマホに置き、アプリの最初の画面で選びます。

```
英語<TAB>日本語<TAB>[sound:...]<TAB>N SECTION   ← 見出し語（タグ付き）
英文<TAB>日本語訳<TAB>[sound:...]<TAB>          ← 例文（タグなし）
```

例文にはセクションの情報がないので、**どのセクションの見出し語を含むか** から自動で判定し、
見出し語と例文を結び付けます（穴埋めの空欄・重要語の表示に使います）。
手元のデータでは 560 文・2569 語・45 セクションに分かれ、見出し語の約 95% が例文に結び付きました。

### 3. 音声フォルダを選ぶ（任意）

`01 トラック 1.mp3` 〜 `45 トラック 45.mp3`（1 トラック = 1 セクション）をスマホの 1 つのフォルダに入れ、設定 → 音声フォルダ で選びます。

- アプリがトラックを解析し、**無音の区間で 1 文ずつに自動分割** します。
- セクション詳細の右上のボタン（音声の調整）で、1 文ずつ聞いて確認できます。ずれていたら「先頭で飛ばす数」「感度」を変えて分割し直してください。
- 分割数が例文の数と合わないセクションや、音声フォルダを選ばない場合は、端末の読み上げ（TTS）で再生します。

## 開発

- Kotlin 2.0 / Jetpack Compose / Material 3、minSdk 26（Android 8.0）
- 画面遷移もデータ保存も最小限の自前実装（Room や Navigation は使わず、JSON 1 ファイル）

```
app/src/main/java/app/duotrainer/
├─ core/        Android に依存しないロジック（単体テストあり）
│   ├─ DeckParser.kt   Anki テキストの読み込み・例文と見出し語の対応付け
│   ├─ TextUtil.kt     見出し語マッチ・英文の正規化・差分
│   ├─ Cloze.kt        穴埋め問題の生成
│   ├─ Srs.kt          復習間隔（忘却曲線を参考に ease 倍ずつ伸ばす × 自信度）
│   ├─ Planner.kt      出題リスト（インターリービング・新出の混ぜ方）
│   └─ Segmenter.kt    CD 音声の無音検出と 1 文ずつの分割
├─ audio/       mp3 のデコード（MediaCodec）・区間再生・TTS
├─ data/        保存（進捗・ログ・設定）
└─ ui/          画面（ホーム・教材・学習・結果・記録・設定・音声の調整）
```

```bash
./gradlew testDebugUnitTest --tests 'app.duotrainer.core.*'
```

```bash
./gradlew assembleRelease
```

手元の DUO データで対応付けを確認するテスト（データはリポジトリに入れないこと）:

```bash
./gradlew testDebugUnitTest --tests 'app.duotrainer.core.CoreTest' -Dduo.file=/path/to/DUO3.0.txt
```

### 署名について

上書きインストールで学習記録が消えないよう、CI のビルドは `app/debug.keystore`（固定の debug 鍵）で署名しています。
自分専用の鍵にしたい場合は、リポジトリの Secrets に `SIGNING_KEYSTORE_BASE64` / `SIGNING_STORE_PASSWORD` / `SIGNING_KEY_ALIAS` / `SIGNING_KEY_PASSWORD` を登録してください（鍵を変えると、一度アンインストールが必要です。先に学習記録を書き出しておいてください）。
